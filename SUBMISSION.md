# Submission

Submit exactly these two values through the course submission channel:

1. The URL of your **public** Homework 2 GitHub repository.
2. The full **40-character** commit SHA to grade.

Do not submit a branch name, tag, shortened SHA, archive, pull-request URL, or
additional repository. The submitted commit must exist in the public
repository and contain the implementation, at least six distinct
student-authored XCTest methods beyond the starter tests, completed `PLAN.md`
and `AGENT_WORKLOG.md`, and any optional evidence you chose to include.

Before submitting, run `swift test`, commit all intended files, push the
commit, and verify that the 40-character SHA shown by `git rev-parse HEAD`
matches the SHA you submit.
